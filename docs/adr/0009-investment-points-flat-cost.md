# Character creation spends the same Investment Points as leveling, at flat cost, with no dump-stats

Character creation had no defined mechanism at all — `NOTES_character_progression.md` described attributes being "raised via investment (leveling, training, etc.)" but never said how a level 1 character gets their starting numbers. Three things needed deciding at once: whether creation is its own system or just investment spent early; whether each point costs more the higher the attribute already is; and whether a character can start below baseline by choice.

We decided all three the "boring" way. Creation is **the same Investment Point mechanism as leveling**, just spent before play starts, from a fixed starting budget (same for every character; exact size TBD during tuning) — not a separate one-time system with its own rules. Each Investment Point always raises a raw attribute by exactly **+1**, regardless of current value — no progressive/escalating cost. And baseline 0 is a hard **floor at creation**: a character cannot dump-stat below 0 to free up points elsewhere. Negative attributes remain exclusively a post-creation consequence (curses, debuffs, drain), never a creation-time build choice.

The flat-cost call matters most, and cuts against the obvious CRPG-point-buy instinct (D&D-style point buy escalates cost near the top of the range): diminishing returns already live entirely in the Effective Value curve (sqrt), per the existing "diminishing returns live at the attribute level" design. Making raw Investment Points *also* cost progressively more would stack two diminishing-returns mechanisms on the same lever — the same kind of double-dampening ADR-0001 already rejected for hit resolution. One curve, one job: Investment Points measure raw spend linearly; the curve alone determines how much power that spend buys.
